# Timmy'sShadow

A mobile-first personal planner for daily habits, journaling, recovery notes, and weight goals.

## Run locally

```bash
npm install
npm run dev
```

Run tests with `npm test`.

## Features

- Dark, responsive planner dashboard
- Date-specific journal, recovery notes, and daily intentions
- Daily habit check-ins with current and longest streak tracking
- Manual food log by date and meal (Breakfast, Lunch, Dinner, Snack) with calories, protein, carbs, and fat, per-meal and daily totals, and edit/delete
- Weight and goal progress
- Automatic localStorage persistence (data stays in this browser/device)
